How to use AutoDS

AutoDS is a local, end-to-end data-science workspace. Load a dataset, understand it, clean it with plain English, explore patterns visually, train models, and use the results to make predictions.

01 / The basic workflow

1. Ingest

Upload a file, paste data, use a public URL, connect to a database, merge datasets, or split a column.

2. Profile

Review column types, missing values, distributions, duplicates, correlations, and automatic suggestions.

3. Clean

Use the controls or type a plain-English command. Every change is tracked and can be undone.

4. Explore and model

Build charts, run simulations, train supervised models, discover groups and anomalies, forecast, or recommend items.

AutoDS works on the currently selected dataset tab. When data changes, current training results are cleared so models cannot silently use stale data; saved runs remain available.

02 / Ingesting data

Supported file types include CSV, Excel (.xlsx), JSON, TSV, Parquet, and SQLite (.db). For CSV-like files, use automatic detection or choose a separator. If the first row is data rather than headers, turn off header row.

You can also paste CSV/TSV text, load a public HTTP/HTTPS dataset URL, use a database connection, merge two loaded datasets, or split one text column into multiple columns.

Tip: after loading, check the preview and detected column types before training. A date stored as text should be converted to date/time first.

03 / Profile and understand

The automated profile summarises row and column counts, data types, missingness, unique values, descriptive statistics, distributions, duplicate rows, and numeric relationships. The assistant can answer questions about the active data and return tables where useful.

Examples: what is the average revenue? · show missing values · which columns correlate with price? · count customers by country · compare sales by region · show the distribution of age.

04 / Clean data with commands

In the Clean panel, type a command in ordinary English. Column names and values are taken from your dataset. AutoDS understands common synonyms and can correct likely keyword typos.

Common keyword families: drop/remove/delete; replace/change/set; move/reorder; fill/populate/update; trim/strip; category/categorical; create/add; convert/change type; extract/pattern/regex; rows/records; missing/empty/null.

Use the structured controls for filtering, changing a column type, handling missing values, removing duplicates, grouping and aggregating, or extracting with a regular expression. For regex extraction, use at least one capture group, for example \d{4}-(\d{2})-\d{2} to capture a month from 2021-09-10.

05 / Visualise patterns

The Visualise panel suggests useful charts and also lets you build your own. Available chart types include histogram, bar, pie, box plot, scatter, line, bubble, stacked bar, area, heatmap, treemap, radar, violin, density, scatter map, density heatmap, choropleth map, word frequency, and word cloud.

  • Use scatter to inspect relationships between two numeric columns.
  • Use heatmap to see correlations across numeric columns.
  • Use line or area for trends over time or ordered values.
  • Use box plot and violin to compare distributions and spot outliers.
  • Use maps when latitude/longitude or geographic region data is present.
  • Use word frequency or word cloud for text columns.

You can keep several charts, add notes to charts, filter chart values, and download charts or the full report.

06 / Machine learning

Supervised learning: predict a target

Choose a target column in Training and choose feature columns, or let AutoDS use the other suitable columns. AutoDS detects classification versus regression and compares several models on a held-out validation split.

Depending on the data, the model panel may include linear/logistic baselines, Random Forest, Extra Trees, Gradient Boosting, Histogram Gradient Boosting, KNN, SGD, and optional XGBoost. Preprocessing handles numeric and categorical features, missing values, and encoding. Review the leaderboard, validation metric, confusion matrix or regression metrics, and feature importance before trusting a model.

Predict

After training, enter one row in the prediction form or use Choose input range to score many combinations. Download a trained model as a .pkl, or import a compatible scikit-learn/XGBoost/LightGBM model for prediction-only use.

Forecast

For a numeric time-like target, use Forecast & compare from a model card. AutoDS compares original and projected values and can show a line, bar, or pie view. Forecasting is an estimate based on the available data, not a guarantee of future outcomes.

What-if simulation

Choose an outcome and driver, then test a percentage or fixed change. AutoDS repeats the scenario across sampled rows and reports a likely range for the sum, mean, or median.

07 / Pattern recognition without a target

Use Unsupervised Learning when there is no answer column to predict and you want AutoDS to discover structure in the data.

Clustering

K-Means, hierarchical/agglomerative clustering, or DBSCAN groups similar rows. Review cluster sizes and the features that separate groups.

Anomaly detection

Isolation Forest, Local Outlier Factor, or similar methods identify rows that do not fit the normal pattern. Anomaly labels and scores can be used to investigate or filter unusual records.

Dimensionality reduction

PCA compresses many numeric columns into a few components while preserving as much variation as possible. A 2D view can reveal clusters and structure.

Association rules

Apriori-style analysis finds items or categories that occur together, using support, confidence, and lift. This is useful for market-basket and co-occurrence patterns.

Recommendations

Fit a content-based or collaborative/implicit model to recommend similar or unseen items. Provide user, item, and optional rating/interactions columns.

A pattern is evidence to investigate, not proof of causation. Check sample size, missing values, leakage, and whether the relationship makes sense in the real-world context.

08 / Ask the assistant

The assistant works locally on the active dataset. It can explain columns, calculate statistics, compare groups, find correlations, suggest charts, recommend cleaning steps, and generate analysis code for clustering, anomaly detection, or association rules.

Try: summarize the dataset · what should I fix next? · show the strongest correlations · make a scatter plot of income and spend · find outliers · analyze clusters · find association rules.

09 / Save, export, and good practice

  • Use dataset tabs to work with more than one loaded dataset.
  • Use undo/reset after cleaning when you need to compare with the original.
  • Download cleaned data, charts, an HTML report, or a notebook from the relevant panel.
  • Save model runs with a name when comparing experiments.
  • Before deploying or sharing results, validate on data the model has not seen and check for leakage, bias, and meaningful business context.

AutoDS is designed for exploration and rapid analysis. Always review automated cleaning, patterns, and model scores before making consequential decisions.
