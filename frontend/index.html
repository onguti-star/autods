Choose supervised learning when you have a target column to predict, or unsupervised learning when you want to discover clusters, patterns, or unusual rows.

Apply a cleaning command before training. Current training results are cleared when the data changes, while saved runs stay available.

Dimensionality Reduction (PCA)

Run PCA to compress numeric features before training. This can speed up training and reduce overfitting when columns are highly correlated.

05 / Unsupervised Learning

Discover patterns without a target column — clustering, anomaly detection, dimensionality reduction, and association rules.

Numeric unsupervised methods use median imputation plus StandardScaler before distance-based analysis, so columns with large values do not dominate the result.
